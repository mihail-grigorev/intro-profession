# Практическая работа 2. Работа с LLM через API

Репозиторий практической работы № 2 по курсу «Введение в профессию».

**Студент:** Григорьев Михаил Романович  
**Группа:** ИСТ.04  
**Вариант:** 26 (`rental_26.csv`)  

## Структура проекта
- `llm_demo.ipynb` — базовое подключение к LLM GigaChat через LangChain, простые промпты и тестирование на 15 заявках.
- `llm_work.ipynb` — полное решение: автоматическая обработка через pandas DataFrame, сохранение в CSV, расчет метрик точности и сравнение техник промптирования (Basic, Detailed, Few-Shot, Chain-of-Thought).
- `rental_26.csv` — датасет заявок на аренду жилья (15 записей).
- `rental_with_results.csv` — результаты обработки заявок моделью с вычисленной точностью.
- `reflection2.md` — рефлексия по итогам выполнения работы.

## Ветки репозитория
- `master` — основная ветка с итоговым решением (`llm_work.ipynb`), результатами и рефлексией.
- `env-feature` — настройка окружения, безопасная работа с ключами через `.env` и базовый ноутбук `llm_demo.ipynb`.
- `llm-improve-1` — расчет точности с использованием pandas DataFrame и сохранением результатов.
- `llm-improve-2` — продвинутые техники промптирования (Few-Shot / Chain-of-Thought) и структурированный JSON-вывод через `JsonOutputParser` для извлечения расширенных атрибутов (`count_adults`, `count_children`, `start_date`, `nights`, `price_per_day`, `remarks`).
