## Структура проекта
- `llm_demo.ipynb` — базовое подключение к LLM GigaChat через LangChain, шаблоны сообщений (`SystemMessagePromptTemplate`, `HumanMessagePromptTemplate`) и первичное тестирование на 15 заявках варианта 06.
- `llm_work.ipynb` — итоговое решение: обработка данных через pandas DataFrame, сохранение предсказаний в CSV, оценка метрик точности (100.0% на базовом промпте) и детальное сравнение 4 техник промптирования (Basic, Detailed, Few-Shot, Chain-of-Thought).
- `rental_06.csv` — датасет заявок на аренду жилья варианта 06 (15 записей).
- `rental_with_results.csv` — датасет с сохраненными результатами работы модели (`amount`, `text`, `result`).
- `reflection2.md` — итоговая структурированная рефлексия по занятию с фактическими метриками и разбором краевых случаев.

## Ветки репозитория
- `master` — основная ветка с итоговым решением (`llm_work.ipynb`), датасетом `rental_06.csv`, результатами `rental_with_results.csv` и отчетом `reflection2.md`.
- `env-feature` — настройка окружения, безопасная работа с ключами через `.env` и базовый ноутбук `llm_demo.ipynb`.
- `llm-improve-1` — расчет точности с использованием pandas DataFrame, сохранение в CSV и сравнение техник промптирования.
- `llm-improve-2` — Задание № 2: продвинутые техники промптирования и структурированный JSON-вывод через `JsonOutputParser` на базе схемы Pydantic для извлечения расширенных полей (`count_adults`, `count_children`, `start_date`, `nights`, `price_per_day`, `remarks`), ручная эталонная разметка и расчет точности по полям (средняя точность 91.7%).
